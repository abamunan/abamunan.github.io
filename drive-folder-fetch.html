Drive Folder Fetch

Paste a public Google Drive folder link, load its contents, then save everything straight to a folder on your computer. No zip is built in memory, so large folders do not crash the tab.

Runs in your browser. Files go between you and Google Drive, never through this site.

  1. Go to console.cloud.google.com and create (or pick) a project.
  2. Enable the Google Drive API for that project.
  3. Under APIs & Services → Credentials, create an API key.
  4. Optional but recommended: restrict the key to the Drive API.
  5. Make sure the Drive folder is shared as "Anyone with the link" — an API key can only read public files, not private ones.

Don't want to set this up? Ask Munan for a one-time API key instead.

  1. Open Google Cloud Console and select the same project you used for the API key (or create a new one).
  2. Make sure the Google Drive API is enabled: open the Drive API page and click Enable if you see that button (if it says Manage, it's already on).
  3. Go to Google Auth Platform (search for it in the top bar), or APIs & Services → OAuth consent screen. If you see a Get started button, click it, enter any app name and your email, choose External as the audience, and finish the wizard.
  4. Open Audience → Test users → Add users, enter your own Gmail address (the Drive you want to save into), and click Save. While the app is in "Testing", only listed test users can sign in.
  5. Open Clients → Create client. Choose Application type: Web application and give it any name.
  6. Under Authorized JavaScript origins, click Add URI and enter the address this page is opened from. For this page that is:

    Use only the site address — no page name and no trailing /. Examples: https://yoursite.com or http://localhost:8000. Leave Authorized redirect URIs empty.
  7. Click Create, copy the Client ID (it ends with .apps.googleusercontent.com) and paste it above. You don't need the Client secret.

Good to know: the page must be opened from http(s):// (a hosted site or localhost), not as a file:// file. Origin changes can take a few minutes to apply. If Google shows "This app isn't verified", click Advanced → Go to (app name) — that's normal for apps in Testing. The sign-in token lasts about an hour and is never stored. You can revoke access anytime at myaccount.google.com/permissions.

Creates a Drive Folder Fetch <date> folder in My Drive with the same subfolders. Fast copy falls back to download & upload automatically if a file can't be copied (e.g. the owner disabled copying). Google may show an "unverified app" warning — add your account as a Test user and continue.
