Drive Folder Fetch

Paste a public Google Drive folder link, load its contents, then save everything straight to a folder on your computer — no zip built in memory, so large folders don't crash the tab.

  1. Go to console.cloud.google.com and create (or pick) a project.
  2. Enable the Google Drive API for that project.
  3. Under APIs & Services → Credentials, create an API key.
  4. Optional but recommended: restrict the key to the Drive API.
  5. Make sure the Drive folder is shared as "Anyone with the link" — an API key can only read public files, not private ones.

Don't want to set this up? Ask Munan for a one-time API key instead.
